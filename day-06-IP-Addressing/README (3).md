# CCNA Day 6 Lab: IP addressing and interfaces of router
## Objective

Use Packet Tracer to get familiar with the IP addressing and make interfaces active to connect to switches 
## Tools Used

- Cisco Packet Tracer
- Command Prompt

---

## Task :
1. Configure R1's hostname

2. Use a 'show' command to view a list of R1's interfaces, their IP addresses, status, etc.

3. Configure the appropriate IP addresses on R1's interfaces, and enable the interfaces
    Configure appropriate interface descriptions

4. Use a 'show' command to verify R1's interfaces again.

5. View the running config to confirm the configuration changes, then save the config

6. Configure the IP addresses of PC1, PC2, and PC3
   (Watch the video to learn how to do this in Packet Tracer)

7. Ping from PC1 to PC2 and PC3 to test connectivity


### used Commands in Command Prompt 

1. hostname - to configure the host name of the router
2. show ip interface brief - to show the details and status about the interfaces of the router 
3. enable - to enter into user prev mode 
4. configure terminal - to enter into configuration terminal 
5. interface 'interface-id' - to access the specific interface 
6. ip address 'ip-address' 'subnet mask' - to assign the ip address and the subnet mask for the specific interface of the router 
7. no shutdown - to cancel the default shutdown configuration in a router or device 
8. used the IP configuration window for the configuration of IP addresses in the PC's
9. ping 'ip-address' - to check the reachability of the PC2 and PC3 

## Conclusion

Got to know about the usage of command prompt to assign IP and change the configurations
